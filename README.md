# California House Price Prediction

End-to-end regression project that estimates **median house value** for California census block groups from 1990 housing data. It covers dataset loading and preprocessing, exploratory analysis, Linear Regression as a baseline, a Random Forest production model, test-set metrics (MAE, RMSE, R²), residual plots, sample predictions, a saved model artifact, a FastAPI inference service, and a React valuation UI.

This repository is the deliverable for **Task 6 — Linear Regression: House Price Prediction**. Linear Regression is trained and evaluated in the notebook; Random Forest is the saved model used by the API because it is stronger on the same held-out test set.

## Results (test set)

| Model | MAE | RMSE | R² |
|---|---|---|---|
| Linear Regression (notebook baseline) | $50,404.86 | $69,353.01 | 0.6330 |
| Random Forest (production, 200 trees) | $30,407.79 | $47,883.47 | 0.8250 |

The production Random Forest uses `n_estimators=200` and `random_state=42`. Residual analysis and five actual-vs-predicted examples are in [docs/evaluation.md](docs/evaluation.md).

## Quick start

Run all Python commands from the **repository root**.

1. Create a virtual environment and install dependencies:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Place the dataset at `data/raw/California_Houses.csv`. Source and columns are documented in [docs/dataset.md](docs/dataset.md).

3. Train and save the Random Forest model:

   ```bash
   python -m src.train_model
   ```

4. Evaluate on the test set (writes `outputs/metrics.csv`):

   ```bash
   python -m src.evaluate_model
   ```

5. Optional exploratory plots:

   ```bash
   python -m src.eda
   ```

6. Start the API:

   ```bash
   uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
   ```

7. Start the frontend (separate terminal):

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

Open the Vite URL (typically `http://127.0.0.1:5173`) and submit a property profile. The UI posts to `http://127.0.0.1:8000/predict`.

A single CLI prediction example:

```bash
python -m src.predict
```
